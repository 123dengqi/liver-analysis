# 数据字典与分析变量

| 分析变量 | 来源字段 | 定义/处理 |
|---|---|---|
| 患者编号 | 姓名 | SHA-256 哈希前8位，仅用于去重和匿名导出 |
| 索引住院 | 姓名、入院时间 | 主分析保留每位成人患者首次有 RFH-NPT 记录的住院 |
| 多重用药 | 出院带药 | 解析不同药物名称，种类数≥5记为是；重复药名按1种计 |
| 高营养不良风险 | RFH-NPT评分 | RFH-NPT≥2记为是；0–1记为否 |
| 年龄 | 年龄 | 主分析排除<18岁及年龄缺失记录 |
| 性别 | 性别 | 统一为男/女；其他编码置为缺失 |
| BMI | BMI | 连续变量，kg/m² |
| 病因 | 病毒、酒精、免疫、PBC/PSC/重叠、其他 | 生成病毒性、酒精性、自身免疫性、胆汁淤积性、其他、混合及未分类 |
| 腹水 | 腹水；出院诊断 | 原表0/1优先；缺失时由出院诊断中的“腹水/腹腔积液”补全 |
| 静脉曲张 | 食管胃底静脉曲张；出院诊断 | 原表0/1优先；缺失时由出院诊断中的“静脉曲张”补全 |
| 肝性脑病 | 肝脑；出院诊断 | 使用“肝脑”0/1，不用CTP计分列；缺失时由“肝性脑病/肝性昏迷”补全 |
| 感染 | 感染；出院诊断 | 原表0/1优先；缺失时由“感染/肺炎/腹膜炎/败血症/脓毒”补全 |
| 糖尿病 | 出院诊断 | 诊断文本含“糖尿病”记为是 |
| 高血压 | 出院诊断 | 诊断文本含“高血压”记为是；排除门脉高压、门静脉高压、肺动脉高压 |
| 冠状动脉性心脏病 | 出院诊断 | 含冠心病、冠状动脉性/粥样硬化性心脏病、支架/搭桥、心绞痛、心肌梗死等；排除冠状动脉肌桥 |
| MELD-Na | MELD评分、MELD Na、Na | 使用原表 MELD-Na，并按 `MELD+1.59×(135−Na)` 核验；Na限幅120–135 mmol/L |
| 年龄组 | 年龄 | <50、50–59、60–69、≥70岁，用于对应参考论文的年龄分层图 |

## 药物文本解析

药物按中文逗号、英文逗号、顿号、分号和换行分隔，去除厂家标记、剂量、给药途径及频次后提取药名。同一条记录内重复药名只计一次。含“继续”“调整”“根据尿量”等模糊医嘱，或既无常见剂型又无剂量证据的文本会进入 `outputs/medication_manual_review.csv`。

## 缺失值

描述性表格按变量可用病例计算分母。多变量 Logistic 回归采用完整病例分析；前端会显示完整病例数。缺失值不进行单次插补。

## 统计解释

主分析以全部住院记录为准，每行作为独立分析个体。首次/末次记录可作为敏感性分析。观察性研究的 OR 表示关联，不能解释为因果效应。
